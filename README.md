## Quick Start

1. **Prepare your console:** Ensure your PS3 can install and run homebrew PKG applications using compatible CFW or PS3HEN.
2. **Install Apollo:** Download the official `apollo-ps3.pkg` package and install it through the console's Package Manager.
3. **Manage your data:** Launch Apollo, select a save, trophy, or license operation, and follow the application's on-screen options.

## Key Features

### Game Save Management
- Browse game saves stored on the internal HDD and USB devices.
- Download saves from Apollo's online database.
- Unlock save files by removing supported SFO copy-protection flags.
- Resign PFD save data for another user or console.
- Apply compatible Bruteforce Save Data and Game Genie patches.

### Trophy Management
- Resign trophy sets for the current user and console.
- Export trophy data in ZIP and raw formats.
- Import trophy sets from USB backups.
- Manage individual trophy entries through the application.

### Account and License Management
- Generate offline PS3 account activation data.
- Export licenses in ZIP and RAP formats.
- Import RAP license files and generate RIF files.
- Automatically detect PSID, IDPS, and Account ID settings.
- Support multiple user accounts.

### Memory Cards and Save Conversion
- Manage PS1 and PS2 virtual memory card data.
- Convert supported PS1 and PS2 save formats to PS3 PSV format.
- Create PS2 Classics images from supported PS2 ISO files.
- Import and export supported Dreamcast VMU save images.
- Work with supported memory card formats and save-data containers.

## FAQ

**1. What is Apollo Save Tool?**

Apollo Save Tool is an open-source PS3 homebrew application for managing game saves, trophies, licenses, and supported memory card data.

**2. Does Apollo require custom firmware?**

Apollo requires a PS3 environment capable of installing and running homebrew PKG applications. Compatible CFW and PS3HEN setups are supported.

**3. Can Apollo resign game saves?**

Yes. Its PFD resigning functionality supports adapting compatible save files for another user or console.

**4. Can Apollo manage PS1 and PS2 saves?**

Yes. Apollo supports various PS1 and PS2 virtual memory card formats, as well as conversion of supported saves to the PS3 PSV format.

**5. Where can I download Apollo Save Tool?**

The official GitHub repository provides source code, installation information, and release downloads. The Releases page lists available versions and changelogs.
